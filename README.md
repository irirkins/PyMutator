Идея проекта:
PyMutator - инструмент для оценивания качества тестов, путем мутаций (намеренных небольших ошибок, например, замена арифметических, логических операций, констант и т.д.) исходного кода. Если тесты проходят на "мутантах" (измененных файлах исходного кода), значит тесты не достаточно качественные и требуют доработки.

Features:
Первая итерация:
    1. Реализация создания "мутантов"
    2. Реализация запуска тестов на созданных файлах исходного кода в изолированной среде
    3. Сбор статистики (сколько мутантов было убито / выжило) и вывод её в терминал
Вторая итерация:
    1. Распараллеливание тестирования различных "мутированных" файлов по разным ядрам процессора для ускорения работы
    2. Создание системы защиты от бесконечных циклов
    3. Поддержка комментариев (# no mutation) для отключения мутации конкретных строк, а также поддержка конфиг-файлов для задания конкретных параметров мутации (например, только арифметические мутации)
    4. Визуализация выживших мутантов в формате diff, а также отображение состояния текущего тестирования (мутанты убиты/выжили)

Библиотеки:
    1. libcst (работа с деревом исходного кода с сохранением форматирования)
    2. psutil (для отслеживания времени исполнения программы и её своевременного убийства)
    3. pydantic (проверка данных в пользовательском конфиг-файле)
    4. rich (красивая визуализация процесса тестирования)
